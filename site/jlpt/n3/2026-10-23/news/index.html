話題: プログラミング言語「PHP」から、重大な脆弱性が発見された。

ウィキペディア日本語版「Portal:最近の出来事」（CC BY-SA 4.0） ／ 元の報道

本文は上の記載をもとに書いたもので、CC BY-SA 4.0 で公開しています。

PHPは、ウェブページを動的に作るための機能を多く持つオープンソースのプログラミング言語です。PHPは「PHP: Hypertext Preprocessor」の略で、HTMLのプリプロセッサという意味を再帰的に表しています。このPHPに、外部から攻撃されやすい重大なセキュリティホールが見つかりました。セキュリティホールとは、不正侵入やデータの改ざんなどが実行できてしまう危険な欠陥のことです。

問1 Q1

本文中の「セキュリティホール」の説明として最も近いものはどれか。

  1. オープンソースとしてコミュニティで開発される仕組み
  2. プログラミング言語の構文を形式的に定義したもの
  3. ウェブページを動的に作成するための便利な機能
  4. 外部からの攻撃で不正侵入やデータの改ざんが可能になる危険な欠陥
答えと解説 Answer

正解 Answer: 4. 外部からの攻撃で不正侵入やデータの改ざんが可能になる危険な欠陥

本文に「セキュリティホールとは、不正侵入やデータの改ざんなどが実行できてしまう危険な欠陥」とある。他の選択肢は本文の別の語句の説明で、セキュリティホールの意味ではない。

English

The passage states that a security hole is a dangerous flaw that allows unauthorized access or data tampering. The other options describe other terms from the passage, not security holes.

問2 Q2

本文によると、PHPの特徴として正しいものはどれか。

  1. HTMLの代わりに使うと決められている
  2. ウェブページを動的に作る機能を多く備えている
  3. 外部からの攻撃を自動的に防ぐ仕組みを持っている
  4. プログラマがいなくても動くように設計されている
答えと解説 Answer

正解 Answer: 2. ウェブページを動的に作る機能を多く備えている

本文に「ウェブページを動的に作るための機能を多く持つ」とある。攻撃を防ぐ仕組みやプログラマ不要、HTMLの代替という記述はない。

English

The passage says PHP has many features for creating dynamic web pages. It does not mention automatic attack prevention, not needing programmers, or replacing HTML.

問3 Q3

このニュースで伝えている主な内容はどれか。

  1. PHPの開発コミュニティが解散したこと
  2. PHPが新しくオープンソースになったこと
  3. PHPの名前の意味が変わったこと
  4. PHPに重大なセキュリティホールが見つかったこと
答えと解説 Answer

正解 Answer: 4. PHPに重大なセキュリティホールが見つかったこと

本文の中心は「PHPに重大なセキュリティホールが見つかった」という知らせである。コミュニティの解散や名前の変更、新たなオープンソース化には触れていない。

English

The main point is that a serious security hole was found in PHP. The passage does not mention the community disbanding, a name change, or PHP becoming newly open source.
