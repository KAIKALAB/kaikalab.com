About Kaika Lab

会社紹介

Kaika Lab（カイカラボ）は、2026年7月に Michael Jiang が大阪で開業したソフトウェア工房です。韓国語と日本語を学ぶ人のための試験対策アプリと学習教材、そして語学を教える先生のための道具を作っています。

事業の仕組み

Business model

収益の柱は、試験対策アプリの定期購入です。TOPIK と JLPT の結果は大学入学や就職で使われるため、学習者には、試験日までに模擬試験と解説にお金を払う理由があります。

無料の学習サイト、単語帳、ドラマは、学習者が最初に私たちを知る入口です。そこから、本番の形式で練習できるアプリへ案内します。

Cloze Maker は当面無料です。インストール数と繰り返し使われる割合を見てから、有料の機能を決めます。JLPT-GO もまず無料の模擬試験から始め、あとで有料プランを加えます。

運営は創業者が1人で行い、サーバーには使った分だけ料金がかかるクラウドを使っています。そのため固定費を小さく抑えられています。

AI の使い方

Claude API

今後は、製品の中で Claude API を使う予定です。文法を説明し、学習者の質問に日本語・韓国語・英語で答える AI チューターと、練習問題と解説を作って点検し、人の監修に回す仕組みに使います。
